## 6. Image Alt-Text Conventions

**Pattern:** `{descriptive content} — {context} — {location if relevant}`

| Image Type | Alt Text Pattern | Example |
|---|---|---|
| Hero images | `{property type} in {location} — {key feature}` | "New construction vacation rental home in Fort Myers Beach, Florida — elevated design with Gulf views" |
| Property renders | `{style} {bedroom count} vacation rental — {design feature}` | "Contemporary 5-bedroom vacation rental with private pool and open-plan living" |
| Infrastructure photos | `{asset name} — {status or significance}` | "Estero Boulevard repair program — $9M infrastructure investment, completion Fall 2027" |
| Development pipeline graphics | `{project name} — {type}, {completion timeline}` | "Margaritaville Beach Resort — 254-room resort, opened December 2023" |
| Dining/lifestyle photos | `{venue name} in {location} — {type}` | "Doc Ford's Rum Bar & Grille on Fort Myers Beach — waterfront dining" |
| Festival/event photos | `{event name} on {location} — {year}` | "Fort Myers Beach Shrimp Festival — annual event on the barrier island" |
| Pillar/feature icons | `{concept} icon — {visual description}` | "Guest experience icon — minimalist star in gold, representing 5-star review focus" |
| Team photos | `{name}, {title} at {company}` | "Carter Dewey, Founder at Purpose Built by Coastal" |

**Rules:**
- Alt text matches SEO keyword targets for the page the image appears on
- No alt text contains "image of", "photo of", or "picture of" (redundant)
- Decorative background images use empty alt (`alt=""`)
- All OG images are unique per page with descriptive filenames

## 7. Technical SEO Requirements

### Required Per Page
- [ ] Canonical tag (`<link rel="canonical">`) — self-referencing
- [ ] Unique `<title>` — 50-60 characters, primary keyword front-loaded
- [ ] Unique `<meta name="description">` — 140-160 characters with CTA
- [ ] Single `<h1>` containing primary keyword
- [ ] Logical heading hierarchy (h1 → h2 → h3, no skips)
- [ ] Primary keyword in first 100 words of body text
- [ ] Secondary keyword coverage throughout body
- [ ] All images have descriptive alt text matching conventions above
- [ ] Schema JSON-LD validates against schema.org
- [ ] Open Graph tags (og:title, og:description, og:image, og:url) unique per page

### Site-Wide
- [ ] `sitemap.xml` — all pages listed with `<lastmod>` dates, no noindex pages
- [ ] `robots.txt` — allows crawling, points to sitemap
- [ ] HTTPS enforced (GitHub Pages default)
- [ ] Custom domain: purposebuiltbycoastal.com with www → apex redirect
- [ ] No broken internal links (full crawl before launch)
- [ ] 404 page exists, branded, with navigation links back to main site

### Performance Targets (from design spec)
- [ ] LCP < 2.5s
- [ ] CLS < 0.1
- [ ] INP < 200ms (if interactive elements exist)
- [ ] Total page weight < 1.5MB
- [ ] Lighthouse SEO score ≥ 95
- [ ] All images served as WebP with lazy loading and explicit width/height

## 8. Content-Brief Summaries (for Copywriting Agent)

Each page brief includes the locked keyword target so copy is written to the SEO plan, not retrofitted.

### Home
- **Keyword:** vacation rental investment homes Fort Myers Beach
- **Angle:** First-impression + value proposition. Communicate "purpose built" differentiator immediately. Lead with the concept, then the market, then the CTA. Keep hero tight — under 30 words.
- **Must include:** "Fort Myers Beach" in H1, "vacation rental investment" in first paragraph

### About
- **Keyword:** Purpose Built by Coastal development team
- **Angle:** Credibility play. Who is Coastal? Why should an investor trust them? Experience, track record, values. Humanize — this is the trust-building page.
- **Must include:** team background, connection to Fort Myers Beach, development philosophy

### What Is Purpose Built
- **Keyword:** what is a purpose built vacation rental
- **Angle:** Educational. Define the concept clearly and contrast with conventional approaches. This is the "aha" page — the reader should finish understanding why design-from-scratch matters.
- **Must include:** "purpose built" in H1, "ground-up" or "from the ground up" in first paragraph, contrast with conversions/rehabs

### Three Pillars
- **Keyword:** vacation rental investment ROI design
- **Angle:** Framework deep-dive. Each pillar gets its own section with concrete examples of design decisions that serve that pillar. Connect design choices to financial outcomes.
- **Must include:** three distinct H2 sections, "ROI" and "return on investment" in body, examples connecting design to financial impact

### Why Fort Myers Beach
- **Keyword:** Fort Myers Beach investment property opportunity
- **Angle:** Market thesis backed by real data. Infrastructure is real. Development pipeline is active. Dining and lifestyle are back. This is the evidence page.
- **Must include:** FEMA CRS Class 5, Margaritaville Beach Resort, Fishing Pier, 40+ restaurants, festival calendar, Estero Blvd repair, San Carlos Blvd corridor — all from the 2026 Investment Prospectus (no financial numbers)

### Investor Overview
- **Keyword:** vacation rental investment Fort Myers Beach returns
- **Angle:** Process and specifics. What does the investment look like? Timeline, property types, what's included. This is the "how it works" page that moves to conversion.
- **Must include:** process steps, property types available, what "turnkey" means, CTA to Contact

### Contact
- **Keyword:** contact Purpose Built by Coastal
- **Angle:** Simple, frictionless conversion. Qualifying fields without creating barriers. Set expectations for response time and next steps.
- **Must include:** form fields that qualify (name, email, phone, investment interest, timeline), response-time expectation

1. **No competitor URLs provided** — keyword research based on topic modeling and search intent analysis only, not competitive gap analysis. Competitor URLs can refine keyword targets if provided later.
2. **Domain purposebuiltbycoastal.com** — assumed as canonical domain. GitHub Pages custom domain setup required.
